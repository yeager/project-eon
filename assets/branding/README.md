# Project Eon branding

`project-eon-logo-v2.png` is the active original Project Eon launcher artwork.
It was created for this project as a retrofuturist EON orbital emblem; it does
not contain, trace, or reproduce pixels from Millennium 2.2 or Deuteros.
`project-eon-logo-v1.png` remains only as an earlier Project Eon branding
revision.

`project-eon-v2.ico` and `project-eon-v2.icns` are format conversions of the
active PNG for Windows and macOS. The runtime uses the PNG, while the native
Windows executable and macOS application bundle use their platform icon
formats. The v1 conversions remain only with their corresponding prior asset.

These files are application branding only. They must never be treated as game
media, evidence for recovered behaviour, or a replacement for original data.
