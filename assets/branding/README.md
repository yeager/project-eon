# Project Eon branding

`project-eon-logo-v1.png` is original Project Eon launcher artwork. It was
created for this project as a transparent retrofuturist orbital-E emblem; it
does not contain, trace, or reproduce pixels from Millennium 2.2 or Deuteros.

`project-eon.ico` and `project-eon.icns` are format conversions of that same
PNG for Windows and macOS. The runtime uses the PNG, while the native Windows
executable and macOS application bundle use their platform icon formats.

These files are application branding only. They must never be treated as game
media, evidence for recovered behaviour, or a replacement for original data.
